# Data

This folder stores local copies of the real and synthetic datasets used by the scripts.

The repository does **not** commit generated or downloaded data files by default.

## Stage 1 dataset

The first baseline uses the published Pima Indians Diabetes split from the official Vicomtech repository:

- training set: E_PimaIndiansDiabetes_Real_Train.csv
- test set: E_PimaIndiansDiabetes_Real_Test.csv

Run:

~~~bash
python -m src.download_data
~~~

to place these files under data/raw/.

Synthetic data generated by the baseline is written to data/synthetic/.

## Data provenance

Upstream project:
https://github.com/Vicomtech/STDG-evaluation-metrics

The original source study describes six open-source health datasets. This reproduction script downloads only the exact files needed for the current baseline.
